# Анализ и прогнозирование потребления домашних хозяйств в регионах России

Учебный проект по анализу временных рядов. Цель работы - сгруппировать регионы России по уровню и динамике потребления, выбрать по одному представителю из каждой группы и сравнить качество прогнозов для этих регионов.

## Данные

Использованы данные Росстата о фактическом потреблении домашних хозяйств на душу населения за 2000-2023 годы. Показатель выражен в рублях на человека в текущих рыночных ценах. После исключения агрегированных записей и регионов с неполными рядами в анализ вошли 79 регионов.

## Ход работы

1. Подготовили годовые ряды и проверили данные на пропуски.
2. Сгруппировали регионы методом K-means по четырем признакам: медианному уровню потребления, медианному годовому росту, росту за весь период и доле годовых снижений. Сравнили решения с двумя, тремя и четырьмя кластерами и выбрали три группы.
3. Для детального анализа выбрали Забайкальский край, Еврейскую автономную область и Мурманскую область - по одному региону, ближайшему к центру своего кластера.
4. Сравнили наивный прогноз, модель Холта и ARIMA на тестовом периоде 2019–2023 годов по RMSE и MAPE. Для лучшей модели дополнительно проверили одношаговый прогноз с расширяющимся окном и разобрали крупнейшие ошибки.

## Основные результаты

Модель Холта показала наименьшие RMSE и MAPE у всех трех выбранных представителей. Для прогноза на 2024-2028 годы ее переобучили на данных за 2000-2023 годы. Наибольшие одношаговые ошибки у всех трех регионов пришлись на 2022 год: фактическое потребление оказалось выше прогноза.

Результат сравнения относится только к выбранным регионам и тестовым годам. Прогноз построен в текущих ценах, поэтому его нельзя трактовать как прогноз роста реального потребления.
